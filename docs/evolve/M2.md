# M2 — orchestrator without Claude

**Done when** (§16): one generation runs end to end with fake agents placed on branches; the faulting
bot is disqualified, the build failure is handled, and three tampered branches are rejected (one edits
`tools/benchmark.py`, one adds a file outside its folder, one uses `#include "../…"`). **Passed 2026-10-22.**

## What was built

| Module | Does |
|---|---|
| `evo/orchestrator/engine.py` | the §5 state machine: PLANNED → TASKS_PUSHED (approval gate, launch preconditions) → RUNNING (launch within the approval and caps, collect, deadline, relaunch, nudge, env_failed) → ADMITTED → EVAL_A/B (one job file per push, results wait and timeout, verification, retry jobs, spot-check, cache, ratings) → SELECTED (survivors, hall of fame, lineage, next-generation plan) |
| `config.py`, `state.py`, `gitops.py` | config with a `[run]` section (ids, file locations, launcher), atomic state file, git via argument lists |
| `tasks.py` + `evo/prompts/` | renders `evo/tasks/<id>.md`; the prompt fragments are placeholders until M3 |
| `launch.py` | `FakeLauncher` (M2) and `same_session` (cse_ ↔ session_); the cloud launcher comes in M3 |
| `collect.py` | finds DONE markers on any remote branch; validates agent, task hash, session, and that `base_commit` is on main |
| `admit.py` | scope from the **merge-base with origin/main** (an agent cannot move its own base), `git archive` extraction (no symlinks), allowlist, copy-in, manifest rewrite |
| `jobs.py` | Stage A/B pair plans (§11), seeded Stage A maps, panel, result cache keyed by (src A, src B, map, runner) |
| `verify.py` | results header and coverage checks (§10.1–3), seeded spot-check sample, local replay with `benchmark.py` |
| `rating.py`, `select.py`, `mutate.py` | §11 table + D22, Bradley–Terry (MM, 1-win/1-loss prior), map bootstrap; survivors + D25 `similar`, largest remainder; D7 rng, operators, crossover partner, evidence, D26 focus, archetypes |
| `maptags.py` | D26 tags in `evo/prompts/map_tags.json` |
| `evo/m2/fake_agents.py` | plays the agents: 8 behaviours by slot |
| `python -m evo …` | `init, approve, step, run, status, verify, spotcheck, maptags` (plus `bootstrap, manifest`) |

Tests: 46 passed, 1 skipped (Windows), including `test_engine.py`. That runs a full generation in a throwaway
repo with a local bare origin and simulated Actions, plus the approval gate, rejection reasons, disqualification,
next-generation planning (elite, 4+2 children, an unused archetype), and a stale-session marker being ignored.

`evo/jobs/tg00-*`, `evo/m2/{state.json,cache.jsonl,lineage.jsonl}`, `results/tg00-*` on `evo-results`, and the
branches `claude/fake-t00-*`. None of it uses the real run's ids or files.
