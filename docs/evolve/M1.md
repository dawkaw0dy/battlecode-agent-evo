# M1 — evaluation pipeline

**Done when** (§16): a hand-written job `probe-random` vs `starter` on 4 maps produces a results file
whose rows match a local `benchmark.py` run. **Passed 2026-10-22.**

## What was built

- `evo/eval/allowlist.py` (+ `std_headers.txt`, 179 headers from the wasi-sdk-33 sysroot): the §8 file, size and include rules (D13).
- `evo/eval/jobfile.py`: build, load and validate job files; `python -m evo.eval.jobfile <id> --pair a:b --maps …`.
- `evo/eval/check_job.py`: `--matrix` for the plan job; `--shard i` re-checks the manifest, runner version,
  both bots' `src_sha256` and allowlist, and the map hashes.
- `evo/eval/extract.py`: §4 rows from `out/<map>-<side>.json` and the replay zip; `build_failed` rows (D22).
- `evo/eval/aggregate.py`: `results/<id>.json` with `job_id, trigger_sha, run_id, run_attempt, workflow_sha256,
  cambc_version, requested_games, missing_shards, shards, rows`.
- `.github/workflows/evo-eval.yml`: plan (exactly one new job file, D24), shard (check, build each bot, play,
  extract, artifacts), aggregate (push `evo-results` with the `evo-actions` deploy key, D20).
- Tests: `evo/tests/test_eval.py` (allowlist incl. 12 tampering patterns, job build/load/check incl. a changed
  bot, map and manifest, extract, build_failed, aggregate). Totals: 30 passed, 1 skipped (Windows).

Its `src_sha256` was computed **on Windows**. `check_job.py` on Linux recomputed it and accepted it (the §0.6
cross-platform digest check, D1).

Actions run 39825910736 → `evo-results` commit `938a8ff` (`github-actions[bot]`, deploy key) → `results/m1-probe.json`:
`trigger_sha 5adaafd…` (= the pushed commit), `workflow_sha256 a27cd342…` (= sha256 of `evo-eval.yml` at that commit),
`cambc 3.0.5`, `requested_games 8`, `missing_shards []`.
